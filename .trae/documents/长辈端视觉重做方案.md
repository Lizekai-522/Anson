# 长辈端视觉重做方案

## 一、目标

只改长辈端（`src/elder/ElderPage.vue`），把「仓促的黑白线框」改成**暖纸底 + 白卡 + 朱红主操作**的成熟长辈界面，同时把字重、层级、留白、状态覆盖做扎实。子女端一行不动。

**用户反馈原话**：只有黑白、特别仓促、字体特别细、长辈看起来不行。

---

## 二、现状诊断（有据可查）

| 问题 | 证据 |
|---|---|
| **全页黑白线框** | `ElderPage.vue` 的 `<style scoped>` 中，`.card` `.panel` `.rest-card` `.tel-btn` `.big-btn` `.code-input` `.bar-btn` `.action-bar` **全部使用 `3px solid #1a1a1a`**；唯一的"重色"是 `.big-btn` 的纯黑实底。品牌朱红 `#C7391B`、暖纸 `#FDFBF5`、衬线字体 `--f-serif` 完全没进长辈端 |
| **字体偏细** | `.card-line2`（站名行）无 `font-weight`，继承 `400`；`.card-title-row` 之外基本是 regular。28px 系统无衬线 regular 在手机上看确实发虚 |
| **层级扁平** | 标题/日期/行程名/卡片同一视觉重量；无"关键信息"突出（时间与站名同色同重） |
| **上方空旷、像半成品** | 单卡时页面下方约 60% 空白；卡片只有 96px 高、18px 内边距，信息密度低 |
| **交互无提示** | 卡片可点开看提示（`toggleCard`），但界面上没有任何"可点"的暗示 |
| **底栏三按钮无差别** | `.bar-btn` × 3 样式完全相同，紧急与播报同权重 |
| **未消费设计 token** | README 声称"所有间距/字号/动效/焦点环都有 token，页面只消费不另造"，但长辈端全部硬编码，与该约定矛盾 |

**必须保住的机器断言与文本锚点**（改造后逐条仍要过）：

- `.elder-h1` 字号 ≥34px；`.card-title` ≥28px；`.card` 宽高 ≥60×60；`.bar-btn` ≥60px 高；**`animationName !== 'none'` 的元素数 === 0**；`nav[aria-label]` 存在；`a[aria-label^="拨打"]` 保留
- 文案/属性锚点：`今日行程`、`链接好像不对`、`输入子女给的 6 位码`、按钮 `/查看行程/`、`#elder-code`、`[role=alert]`、卡片内车次文本
- 类名锚点：`.elder-root` `.elder-h1` `.card` `.card-title` `.bar-btn` `.big-btn`（测试选择器直接依赖）

## 三、设计语言（本次定稿，执行时照抄）

### 3.1 新增长辈端 token（写进 `src/styles/global.css` 的 `:root`）

```css
/* 长辈端专用刻度：暖纸底 + 白卡 + 朱红主操作。长辈端只消费这些 token，不再硬编码颜色 */
--el-bg: #FDFBF5;         /* 暖纸底（与墨字对比 16.8:1） */
--el-card: #FFFFFF;       /* 白卡 */
--el-ink: #1A1A1A;        /* 正文墨色（白卡上 17.4:1） */
--el-ink-2: #4A4A4A;      /* 次级文字（白卡上 8.9:1） */
--el-line: #E4DCC8;       /* 暖色描边 */
--el-tint: #FBEADF;       /* 暖色胶囊底（配 --el-tint-ink 7.4:1） */
--el-tint-ink: #8A2A12;   /* 胶囊文字（深红棕） */
--el-danger: #8F1D10;     /* 紧急深红（白字 8.9:1） */
--el-stay: #8A5A2B;       /* 住宿暖棕 */
--el-shadow: 0 2px 10px rgba(90, 62, 30, 0.10);
--el-r: 18px;             /* 长辈端统一圆角 */
```

朱红继续用既有 `--c-brand: #C7391B`（白字 5.21:1，AAA 大字达标），不另造品牌色。

### 3.2 排版规则

| 用途 | 字体 | 字号 | 字重 | 颜色 |
|---|---|---|---|---|
| 页面大标题 `.elder-h1` | `--f-serif` 衬线 | 44px | 700 | `--el-ink` |
| 日期行 | 无衬线 | 34px | 600 | `--el-ink-2` |
| 行程名 / 小结行 | 无衬线 | 32px | 600 | `--el-ink-2` |
| 车次 `.card-code` | 无衬线 | 36px | 700 | `--el-ink` |
| 类型词 `.card-title` | 无衬线 | 30px | 600 | `--el-ink` |
| 站名行 `.card-line2` | 无衬线 | 32px | 600 | `--el-ink` |
| 时间 `.card-line3` | 无衬线 | 34px | 700 | `--el-tint-ink`（暖色胶囊内） |
| 提示 `.tip` / 面板正文 | 无衬线 | 28–30px | 500–600 | `--el-ink` |

- `.elder-root` 增加 `-webkit-font-smoothing: subpixel-antialiased`（全局 `body` 用的是 `antialiased`，会把中文显细）
- 正文行高 1.6，卡片内行高 1.5

### 3.3 形状与质地

- 卡片/面板：白底 + `2px solid var(--el-line)` 描边 + `--el-shadow` 阴影 + `--el-r` 圆角（**不用 3px 黑框**）
- 行程卡左侧 8px 强调条：ride 用 `--c-brand`，stay 用 `--el-stay`
- 图标徽章：48px 圆底 + 白字 CJK 字符（车/飞/住），ride 底 `--c-brand`、stay 底 `--el-stay`
- 主操作按钮：朱红实底 + 白字；紧急按钮：`--el-danger` 实底 + 白字；次操作：`--el-line` 描边 + 白底墨字
- 一律**不写** `animation` / `transition`（零动画契约不变，展开收起走 `v-show` 静态切换）
- **禁止 emoji**：所有视觉符号只用 CJK 字符（行/车/飞/住/安）、几何字符与纯 CSS 图形

## 五、假设与决策

| 决策 | 理由 |
|---|---|
| **放弃"纯白底"红线，改判"浅色底 + 对比度 ≥7:1"** | 用户明确选择暖纸底色；#FDFBF5 与墨字对比 16.8:1，可读性无损，而"亮度 ≥0.8 + AAA 对比度"是比"必须精确等于白色"更贴近目标的机器指标 |
| 只用朱红 + 暖纸 + 墨色系，不按行程类型分色 | 用户选择"品牌克制配色"；类型差异靠图标字符（车/飞/住）与「今天住：」前缀表达 |
| 零动画契约不变（不写 `animation` / `transition`） | 机器断言只测 `animation`，但契约同时写在页面注释与 README，属人工红线，本次不放松 |
| 禁用 emoji，符号只用 CJK 字符与纯 CSS 图形 | 用户明确要求；且品牌语言本来就是印章汉字（行/车/飞/住/安） |
| 不改子女端任何文件 | 用户明确「就改长辈端就行」；`--el-*` token 追加在 global.css，对子女端无副作用 |
| 不动 `buildElderCards` 数据契约与分享编码 | 字段被单元测试锁定，且本次是纯视觉改造 |
| 保留全部 e2e 文本/类名/id/role 锚点 | 四个 e2e 文件都依赖它们，改了就是无谓回归 |
| 新增小结行与卡片提示行 | 属已有信息的展示层补充（`todayCards.length` 与 `tips` 都已在页面里），用于解决"空旷"与"无点击暗示"，不引入新能力 |
