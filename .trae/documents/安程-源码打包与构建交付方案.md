# 安程 · 源码打包与构建交付方案

> 用户诉求（原话）：**把整个项目干净的打包成 zip**；**zip 里要有「如何构建起来」的说明**；**然后帮我把项目构建起来，我要看看效果**。

## 2. 打包范围（决策：什么叫「干净」）

**排除**
- `node_modules/`（76M，靠 `npm install` 重建）
- `dist/`（构建产物，且本轮会现场重建）
- `.uploads/`（用户上传的原始压缩包，26M，不属于代码）
- `tests/screenshots/`（视觉基线是 e2e 生成物，跑测试会自动重建）
- 根目录旧产物 `安程-v1.0.0-全量.zip`、`安程-v1.0.0-快照.zip`
- `tests/.lock`、`*.log`、空目录 `.screenshots/`

**包含**
- 全部源码：`src/`、`server/`、`public/`（含 29 个闽南语 mp3 共 285K）、`tests/`（不含 screenshots）、`scripts/`
- 工程配置：`package.json`、`package-lock.json`、`vite.config.js`、`index.html`、`Dockerfile`、`nginx.conf`、`.gitignore`、`.github/workflows/ci.yml`
- 说明文档：`README.md`（本轮校正）+ **新增 `构建与运行说明.md`**
- `.trae/documents/`（200K，本轮与上几轮的改造方案，纯文本，作为书面交付依据保留）

预计 zip 体积 **500K~800K**（mp3 几乎不可压缩）。

## 3. 改动清单

### 3.1 新增 `构建与运行说明.md`（zip 里的「如何构建起来」）

一份照着敲就能跑起来的步骤文档，结构：

1. **30 秒看到效果**（最短路径）
   ```bash
   npm install
   npm run build
   node server/notify-server.mjs --serve-dist   # http://localhost:5180
   ```
   并说明：想纯静态就 `npm run preview`（5190）；想双击即开就 `npm run build:single` 后打开 `dist/安程-单文件.html`。
2. **环境要求**：Node ≥ 18（CI 用 22）、npm；可选 ffmpeg/ffprobe（只在重新生成闽南语音频时才需要）、python3（同）。
3. **依赖安装**：`npm install`（说明 `package-lock.json` 已锁定版本，可用 `npm ci` 复现）。
4. **开发 / 构建 / 预览**：四条命令 + 端口 + 产物落在哪（`dist/`、`dist/安程-单文件.html`）。
5. **三种跑法各能看到什么**：
   - `npm run dev`：热更新开发态；
   - `npm run preview`：生产静态产物，**没有 /api**（同步面板显示「仅同设备可见」、天气按钮提示连不上——这是如实降级，不是坏了）；
   - `notify-server --serve-dist`：**推荐看效果**，同源带 `/api/sync/*`（子女端能看到长辈端实时动作/位置）与 `/api/weather`（能查到目的地天气）。
6. **可选：真的发短信/邮件**：`cp server/.env.example .env` 填服务商 → 重启服务；不填则自动回落本机 App。
7. **测试**：`npm run test:unit`（不需要浏览器）、`npx playwright install chromium` 后 `npm test`（含 e2e）、`npm run test:pwa`。
8. **重新生成闽南语音频包**（可选项）：
   ```bash
   python3 -m pip install torch --index-url https://download.pytorch.org/whl/cpu
   python3 -m pip install transformers scipy
   HF_ENDPOINT=https://hf-mirror.com python3 scripts/make-minnan-audio.py
   ```
   并指向 [NOTICE.md](file:///workspace/public/audio/nan/NOTICE.md)（模型 CC-BY-NC-4.0 非商用、机器合成未试听、要清空清单即自动降级）。
9. **常见问题**：`vite: not found`（`node_modules/.bin` 缺失 → 重跑 `npm install`）；5190/5180 被占用怎么换；`npm test` 报找不到浏览器；沙箱/离线环境下 huggingface 被挡（用镜像）；长辈端「显示设置里没有屏幕常亮那一行」= 浏览器不支持 Wake Lock（如实隐藏，不是 bug）。
10. **目录导览**：把本轮新增的 `src/core/{map,sos,weather,elderVoice}.js`、`src/pages/ReceivePage.vue`、`public/audio/nan/`、`scripts/make-minnan-audio.py` 补进去。

### 3.3 `.gitignore` 补 `.env`

构建说明会让用户创建含密钥的 `.env`；补一行 `.env`（顺带 `!.env.example` 明确示例文件要保留）。这样打包与提交都不会带密钥。

### 3.4 生成 zip

```bash
cd /workspace
zip -qr /tmp/ancheng-src.zip . \
  -x "node_modules/*" -x "dist/*" -x ".uploads/*" -x "tests/screenshots/*" \
  -x "tests/.lock" -x "*.log" -x ".screenshots/*" \
  -x "安程-v1.0.0-全量.zip" -x "安程-v1.0.0-快照.zip"
mv /tmp/ancheng-src.zip /workspace/安程-完整源码-2026-10-11.zip
```
- 先写 `/tmp` 再移入，避免 zip 把自己也打进去；
- 生成后用 `unzip -l` 核对「不含 node_modules/dist/.uploads」且「含 `构建与运行说明.md`、`public/audio/nan/*.mp3`（29 个）、`package-lock.json`」。

## 4. 假设与决策

| 项 | 决策 |
|---|---|
| zip 是否含 `dist/` | **不含**（用户要「干净」；产物由构建步骤现场产出，zip 里保证可复现） |
| 已构建产物怎么给 | 构建后**单独**把 `dist/安程-单文件.html` 与预览服务给用户看，不进 zip |
| `.trae/documents/` | **包含**（改造方案是书面交付依据，纯文本、200K）；若用户不要，一句话即可去掉 |
| `tests/screenshots/` | **排除**（e2e 生成物，会自动重建） |
| 预览用哪种 | 主推 `notify-server --serve-dist`（能演示同步与天气）；`npm run preview` 作为纯静态兜底，两者差异写进说明 |
| README | 只做事实校正 + 指向新文档，不重写、不改结构 |
| 不改范围 | 不动任何产品代码与测试；只新增/校正文档、补一行 `.gitignore`、产出 zip 与构建产物 |
